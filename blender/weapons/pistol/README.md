# Pistol V1

Original blocky game weapon, matching the M4A1 style anchor.

Dimensions: 0.2730 m long, 0.0520 m wide, 0.2270 m high. 264 triangles; 1 mesh(es); one packed 64x64 atlas and one material.

See [family README](../README.md) for GLB export, preview links, marker positions, runtime conventions and validation, and [style guide](../WEAPON_STYLE_GUIDE.md) for future weapons.
