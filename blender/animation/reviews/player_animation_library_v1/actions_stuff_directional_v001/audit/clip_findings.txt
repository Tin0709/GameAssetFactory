Literal clip evaluator minimum
Eight directional clips only require numeric vectors, scalar expression evaluation, and default linear interpolation between numeric keyframe vectors. No Catmull-Rom/pre/post inside these eight. Missing rotation/position=[0,0,0], missing scale=[1,1,1]. Sample authored keyframe times exactly and densely sample analytical channels.
Molang trig is degrees. Need sin, cos, atan, min, max, abs, clamp, ternary > test, + - * /. Backward fcsrsv and lateral pmgjno/qzziyu waist position use ternary and atan; accepted Run evaluator lacks both. Do not replace these with generic bounce functions.
Accumulate source local channel values at their literal weights before forming transforms; do not blend completed actor transforms/quaternions in place of source-channel composition. Holding needs ordered `this` channel semantics. Full runtime may require stateful scripts and additional Molang operators beyond this minimum.
Run leg scale is authored: vertical model Y peaks 1.07. All four Run clips contain leg rotation, position, scale; all four Walk clips contain leg rotation and position only. Side Run arms omit position while forward/backward Run arms have it.
Backward Walk is separately authored: swing amplitude 24 degrees vs forward 37.2; waist/head phase offsets differ. Side Walk/Run legs swing chiefly about source Z with +/-5-degree source X offsets. Side arms are distinct poses. Therefore replaying a rotated forward gait is not source adaptation.
Walk side-loop seam: fpushb leftleg.position at phase0=[.078,.7,0], phase1=[0,.7,0]; dfajpq [.922,.7,0] vs [1,.7,0]. Preserve raw endpoint and evaluate loop boundary explicitly; no silent closing-key replacement.

Native transform adaptation
Both studies preserve native 1.8m proportions, source shoulder pivot two model units below shoulder cap, source legs independent of waist/hips. Keep independent source leg matrices and solve away native Hips inheritance.
Coordinate C=[[-1,0,0],[0,0,1],[0,1,0]], translation=(sourceX,sourceZ,sourceY)*unit.
Run uses R=C*(Rz(z)*Ry(-y)*Rx(-x))*C^-1; scale diagonal(sourceX,sourceZ,sourceY). Transform T(position)*T(pivot)*R*S*T(-pivot).
Walk accepted source uses C*BlenderEuler(-x,-y,z,ZYX)*C^-1, with no source scale. This order differs from Run explicit RzRyRx. Preserve per-study transform mode if unchanged accepted straight behavior is mandatory; a unified corrected runtime mode changes accepted Walk.
Root bank must affect body AND independent source legs. Entity-relative head rotation cancels root/waist/body rotations but keeps transformed head-pivot translation. Root facing derived from source runtime is distinct from trajectory travel direction; legitimate actor yaw does not justify turning forward gait into every direction.

Accepted-study mismatches that must be declared
Walk: isolated full-weight forward clip, fixed .8s loop, ZYX adaptation, parent-relative head, no bob/holding/turn/controller layers, floor lowered38mm, no contact correction.
Run: full-weight forward clip plus life-time bob, held sprint endpoint2s, holding attenuation, phase1.6/s, XYZ/exact matrix order, entity-relative head, bank0, terrain0. It is not a full dynamic input runtime.
Neither existing source evaluator is sufficient as-is for all directional clips/runtime. A faithful adaptation should add literal clip channels and required evaluator operators, keep each accepted transform mode, and declare the differences from complete engine runtime.
