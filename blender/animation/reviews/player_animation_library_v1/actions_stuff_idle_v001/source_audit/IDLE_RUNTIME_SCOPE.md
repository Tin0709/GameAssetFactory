# Runtime and primary performance scope

The primary deliverable is one finite 9-second ordinary default player study (`v.tnlxsa=0`), not a seamless loop. The previously accepted locomotion runtime/geometry profile (`v.tnlxsa=2`, Rana morph option) remains untouched. The source's normal and egjh9 family `tculwn` body channels match; no Rana-only chooser branch is used in this new study.

`IdleRuntime` reads `idle_source_payload.json`, compiled directly from the SHA-verified resource archive. The payload carries all 584 source clips and 80 source controllers referenced by the player entity. Main animation traversal uses the actual `rzkmtm/default` order and follows nested local-player `okjrob/eryuvy` into `kcexxa/default`; the emitted body stack orders bob/holding before source look, then autonomous idle. It does not force a clip, alter its clocks or keys, change the chooser, smooth the pose, close the endpoints, lock feet, or hand tune source PRS.

Declared history for the primary trace: entity lifetime 12 seconds, attack-free age 12 seconds, cumulative modified distance moved 1 (a previously walking player), currently zero horizontal/vertical speed, fixed body/head yaw zero, target pitch zero, unarmed both hands, grounded, local, third-person, alive, dry, no cape, normal terrain. The history helper declares just-stopped prior history; it initializes no long-idle state or clip clock. Source velocity/directional variables are settled zero at sample start.

A caller may use `IdleRuntime.relaxed(seed=2,initial_life=12.)`, then `step(dt,idle_query())`, or `sample_primary(duration=9.,hz=240)`. `sample_primary` includes both endpoints and labels its first fixed-dt source evaluation as viewing time zero. Entity lifetime at time0 is therefore 12+1/240 seconds. All later lifetime phases remain continuous. Snapshot rows expose full upstream body PRS, variables, source controller states/clocks, layers, events, source profile, history, RNG draws, and engine conventions. Persisted rows replace callable queries with sampled values and named query conventions.

Source random API is adapted to Python `random.Random(seed)` / MT19937 inclusive integer ranges. Seed2 naturally draws 1 from 1..12 at `blzrmm`, selecting `tculwn` without a forced branch. Bedrock's actual PRNG is not claimed to match Python. The 240Hz timing is recorded in `primary_timeline.json`: gesture starts viewing t=3.0083333333, transitions to fade at t=7.2166666667, returns to quiet waiting t=7.5666666667. Its authored animation length is 4.2083, fade .2 seconds. Another selection does not occur within the primary nine seconds.

The runtime reuses byte-copied frozen Catmull-Rom interpolation, controller clocks, and outgoing source-duration fades. Its recursive source traversal preserves mixed clip/controller ordering and accumulated-axis `this`. Positive-only unnormalized layer weighting, duplicated spline endpoints, one ordered transition/controller/fixed step, new-state sampling at zero, linear outgoing fades with continuing clocks, `Math.ease_in_out_back` constants, and `this` interpretation are explicit emulator conventions. Bedrock engine VM ordering/precision/fades and cross-controller state are not measured by the archive. State thresholds have fixed-step floating-point quantization. Do not advertise this as binary-identical Bedrock playback.

The study reconstructs upstream eight-bone skeleton channels only. It deliberately omits facial driver bones and source blink/expression rendering, which require a separate face rig and output adapter. The later pack `wqleol/owltad` capture-to-variable and geometry pipeline is outside the channel reconstruction. `humanoid_base_pose` exists in the pack with no bone channels. Top-level built-ins `animation.player.move.arms` and `.move.legs` have weight0.001 but no implementation in this pack; their Bedrock-internal channels are not invented. Source cape channels are present in the payload but no cape is rendered in this profile. Equipment/UI/morph/hurt/spawn special branches and airborne/sneaking are outside this finite ordinary-ground study. Ground motion and head-look interruptions are supported and checked; primary look/motion remain zero.

Automated behavioral verification covers never-moved gating, initial/recent ten-second gating followed by three quiet seconds, natural seeded selection and duration, outgoing source fade and rearm, head/motion interruption, attack reset, body/leg key values, cancel-layer `this`, lifetime-driven bob closure and amplitude, serialization/time labeling, and rejection of excluded special input. These tests live in `test_idle_runtime.py` and exercise the actual source payload/runtime, with no mocked source clips.
