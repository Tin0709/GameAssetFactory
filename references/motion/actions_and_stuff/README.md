# Original motion reference recordings

Byte-identical user-provided footage preserved for research reproducibility and Windows/macOS migration. `manifest.json` records original source paths, SHA256 and bytes. These files are reference videos, not animation/keyframe assets from the resource pack. Existing research charts/observations remain unchanged.

The deep-study `portable_inputs.py` reads these files using repository paths and verifies hashes. See docs/setup/MACBOOK_SETUP.md. Do not redistribute source pack assets or treat screen-space proxies as rig measurements.
