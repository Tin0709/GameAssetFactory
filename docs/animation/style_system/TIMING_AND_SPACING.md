# Timing and spacing

Variable spacing makes action decisive. **S**=source verified, **O**=observed pixels, **A**=project adaptation, **P**=original proposal, **U**=unknown. Effects/recommendations below are **P**; mechanisms are **S**. Continue the [bible](MOTION_STYLE_BIBLE.md).

| Principle | Verified basis | Intended effect and artistic purpose | Rig adaptation; use / avoid |
|---|---|---|---|
| **6. Snappy acceleration/deceleration** | **S:** ordinary gait has unevenly spaced linear limb keys alongside analytic body waves. [P03](SOURCE_EVIDENCE.md#p03) | Fast exchange followed by a more readable open pose creates urgency without a teleport. | **P:** change angular spacing on the existing rigid limb. Use larger increments through ambiguous passing; avoid constant angular speed or extra neutral holds. |
| **7. Curve shape and through-motion** | **S:** gait value closure does not guarantee matching slopes; two lateral Walk tracks even differ at their endpoints. [P03](SOURCE_EVIDENCE.md#p03) | Continuous arrival feels connected; deliberate extrema remain legible. | **P:** inspect one-sided pose/velocity at keys and loop boundaries. Use zero velocity at a chosen extremum, continuing velocity through transit; avoid assuming “source verified” means an ideal C1 loop. |
| **8. Molang/runtime clocks** | **S:** gait uses persistent phase, Jump/Landing use local seconds, bob uses lifetime. [P01](SOURCE_EVIDENCE.md#p01), [P05](SOURCE_EVIDENCE.md#p05) | Locomotion continues while a transient has its own clear beginning and recovery. | **P:** document each control's clock before baking/mixing. Use separate gait and event clocks; avoid forcing a lifetime overlay into one short seamless cycle. |
| **9. Calibrate cadence to travel** | **S:** cadence depends on filtered normalized speed and lateral direction; clipping speed normalization loses unique physical-speed information. [P02](SOURCE_EVIDENCE.md#p02) | Steps cover believable distance and retain directional character. | **P:** measure target travel per cycle on both rigs. Use a declared distance/cadence adapter when needed; avoid copying source Hz as a universal speed or changing travel without checking slip. |
| **10. Preserve phase through handoffs** | **S:** ground states share phase and use speed hysteresis; sprint Jump explicitly reseeds phase to .05/.55. [P02](SOURCE_EVIDENCE.md#p02), [P05](SOURCE_EVIDENCE.md#p05) | The receiving side remains coherent across gait changes and recontact. | **P:** map semantic lead/support events before retiming. Use persistent phase with explicit event overrides; avoid resetting every clip to frame one or overriding an intentional handoff. |

For a new original, mark receive, load minimum, release, pass, open and next receive; these are **P authoring landmarks**, not measured source support percentages. Compare normalized phase and seconds separately. Inspect maximum consecutive displacement at native 30 FPS; a numerical bound does not prove fluidity.

Test both leading feet. Crossfade duration cannot repair incompatible support. Preserve [approved timing controls](APPROVED_REFERENCES.md); follow the [existing workflow](../ANIMATION_WORKFLOW.md). Do not retime approved sources during analysis.
