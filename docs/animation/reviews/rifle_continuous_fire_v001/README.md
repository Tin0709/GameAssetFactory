## Integration

The read-only exporter samples the complete evaluated approved recoil at its original times, including translation and live support, into a separate 13 KiB research AnimationLibrary. The runtime applies the upper-body delta from the shot’s approved AimF85 reference **after** the existing pose writer and removes that delta before the following evaluation. Thus recoil cannot feed the inertializer, change gait/pelvis/legs, or accumulate across shots. Full Aim reconstructs the approved shot; Ready/moving/jump layers receive its relative response without being replaced by a frozen Aim pose. The accepted 180° rectangular-arm frame adapter remains intact. Right attachment and left support are reconciled after the overlay and at interpolated render poses, using the existing presenter.

The dev fire rate is **6 Hz / 360 RPM**, matching the approved 1/6-second impulse/recovery. This intentionally differs from the generic production rifle profile’s 0.12 s interval, which would interrupt this clip’s recovery. Existing profile damage12, projectile speed20 m/s, range15 m and flash settings are reused. Firing follows the actual rifle barrel and current character heading; RMB orbit remains observational. No cursor targeting, aim slowdown or camera recoil is introduced.

The production CombatDirector expects its own enemy registry, auto-targeting and movement gate, so it is not attached wholesale to this scene. A small scene-local adapter retains the existing projectile, flash and impact meshes/materials, swept-ray collision mask/exclusion and zombie `take_damage` contract, and `combat_audio.gd` events. It replaces those effects’ one-shot deletion lifecycle with fixed pools:16 tracers,8 impacts,1 flash and existing bounded audio voices. No new node is created per shot. Pooled objects reset interpolation on reuse, and the muzzle flash follows the same interpolated rifle frame as the hands. The existing gunshot audio is reused; no new rifle sound asset is invented.

One shot is emitted per due physics tick, never a catch-up backlog after a stall. Releasing LMB stops new shots while the last recoil recovers. Cooldown survives click spam; release is observed before GUI handling to avoid stuck firing. Focus loss releases both controls; reset cancels shots/effects. Walk2.70/Run~7.55m/s, original gait cadence, direction, jump physics, camera and approved Ready↔Aim behaviour are preserved. WorldMap and production scripts/resources are unchanged.
