# Historical tool portability limits

The following pre-existing authoring/review/fixture tools retain workstation paths or Windows-only font/executable assumptions. They are preserved because rewriting/re-running them can regenerate approved data. Use the portable launcher and current exported assets. Adapt a specific historical tool under a separate backed-up task before using it on Mac. Original reports may intentionally retain their source-machine paths as provenance. The old research verify_research.py also pins an old Git scope and writes historical verification.json; use the migration report for current source integrity.
