# Geometry-filtered actor sky phase field

In the existing main WorldMap, press F5 then L. At Night or the warm transition, compare **Player - spatial sky phase field (experimental)**. It requires captured sky phase response. It defaults OFF; Noon is an explicit unchanged bypass. Missing private proof or unsupported contexts retain previous lighting. No new scene, asset, controller, camera, shader or material parameter was created for this effect.

The independent CPU adapter replaces the actor's existing incident sky values, consumed by diffuse and the existing broad rough-reflection proxy. It uses the same original GAF voxel field and reserve approximation, with actual captured environment inputs stored privately. It filters source directions through geometry before calculating phase-relative changes, instead of applying a uniform RGB change. Runtime interpolates the source numerator before dividing out the already-applied mean response. Original clock placement, mirrored evening, yaw registration, voxel visibility/reserve, broad reflection and native radiometry remain approximations; this is not recovered Lumen.

The approved baseline resource/data are pinned, and eight external phase payloads are checked by SHA256, schema, bounds and exact Noon identity. Loading is editor-only and lazy; no proprietary coefficients, cubes or arrays are embedded in this repository or loaded by exports. This guard does not certify other private showcase assets for distribution.

Validation includes 26 original-fixture checks; 123 actual integration checks; existing player transport121, player material105, phase44 and a 300frame cycle; moving/jumping/combos at render30/60/120 with physics60 and zero feature/repeat trajectory differences. Thirty matched images restore exactly in all10 cases, including unchanged Noon. The 1024direction correction gives4.66% relative L2 versus an independent98304direction original-model oracle at six off-grid poses. This measures our source-response approximation, not native rendered-image error or whole-map acceptance. The failed128direction result remains saved.

The effect is intentionally optional. Actor face-fill changes are modest; coherent terrain/vegetation response still needs study. Desktop forced refresh adds about0.053ms CPU, with no resolved GPU median difference in this run. First activation took about120ms and retains6,428,160bytes of CPU data until closing the map. Noon does not load the payload on a fresh start. No phone FPS, power or thermal claim; activation and memory need further optimization before default promotion.
