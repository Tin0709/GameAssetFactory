# Meadow Daylight V4 — terrace contact review

Current F5 WorldMap preset. Keeps V3 lighting, exposure .96, warmth .05,
textures, ground palette and the approved short-grass blend. Versioned
ground/cutaway/plant shaders share stronger soft wall-foot and concave-corner
shading from the existing terrain height field. Ground contact wraps around
diagonal block tips; coplanar seams and convex wall edges are left untouched.

V1–V3 shaders/presets, frozen V1 ZIP, source GLBs, Blender assets, placement,
collisions and character animation remain unchanged. This is local shading,
not a renderer change or evidence of the reference game's internal technique.
The height field's earlier overhang/multi-level limitations still apply.

Appearance awaits human review; phone 30 FPS remains unverified.
