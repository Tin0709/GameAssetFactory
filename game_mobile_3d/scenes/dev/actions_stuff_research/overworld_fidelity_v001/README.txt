PRIVATE OVERWORLD FIDELITY MAP

Open res://scenes/dev/MD2OverworldFidelityTest.tscn, F6. F8 stops the previous run.
Or use MD2 Research/godot_lab/overworld_fidelity_v001/Open Overworld Meadow.cmd.
WASD run, Shift walk, Space jump, LMB/E Sabre; R reset, V overview, H hide UI.
Wind, contact, ambience and footsteps/rustle toggles plus audition trims are at left.
The existing source-animation panel is available through Player / animation controls.

This map inherits the existing lab. Controller, character, clips, camera, lighting,
fog, exposure, postprocess and grass shadow policy are preserved.32m visual terrain
surrounds a24m bounded playable area. No new Godot project or production integration.

All original meshes/UVs/textures/audio are read transiently from an external,
ignored private bundle and source files in MD2 Research. Editor binary only;
the map fails closed in exported builds or when its approved source hash changes.
No imported proprietary texture/audio/model resources are saved in res://.

Exact source media and reflected numeric defaults are distinguished from own
adapters. Wind waveform, root-mask substitute, scattering, scatter/ecological
selection, spring response, audio looping/layering/mix/attenuation falloff are
reconstructions. Native max audio radius is source-backed; native Wwise bank
mix/container graphs and ordinary dirt-media mapping remain unresolved.

Private evidence, source pins, pixel captures and30/60/120Hz tests are beside the
bundle. Desktop measurements are not a mobile performance certification.
