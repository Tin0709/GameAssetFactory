# Actions & Stuff Walking and Running gameplay research

Open `res://scenes/dev/ActionsStuffWalkRunTest.tscn` in the existing `game_mobile_3d` project and press **F6**. F5 still opens WorldMap. WASD walks, Shift runs, releasing Shift returns to Walk, releasing movement replants into Idle, and R resets position. Right-drag orbits the camera; the wheel zooms.

This private scene uses `Walk_ActionsStuff_Source_Test_v001` and `Run_ActionsStuff_Source_Test_v001` on the existing full-arm player mesh, rig, atlas and proportions. Older Expressive/Snappy moving clips are not selected. The existing approved Expressive Idle supplies the stationary pose. The Blender sources, Actions and Showcases remain unchanged.

## Source playback

`source_library.res` contains all evaluated position, quaternion rotation and scale tracks for twelve native bones: 385 Walk sample times over 0.8 seconds and 2,996 Run sample times over six seconds. Sample times retain every original baked key, including source breakpoints; no key reduction or generic gait replacement is used. The existing GLB supplies the unchanged geometry/rest rig and fixed helper bones. All 121,716 imported track key values match the Blender export exactly; maximum key-time quantization is 0.223 microseconds. Provenance hashes are in `source_provenance.json`.

Walk plays the accepted saved Action, including its original Blender ZYX convention, at **1.25 cycles/s** at nominal travel. Run reproduces its declared full-forward, full-speed profile at **1.6 cycles/s**, including Run, settled Sprint, lifetime Bob, held-right-arm X attenuation, entity-relative Head, independent leg hierarchy compensation, translations and the **1.00–1.07 leg-Y scale pulse**. Molang sine/cosine use degrees. Source default linear keys and dynamic expressions are evaluated without replacing their timing with smoothing curves. Run uses the separately verified `Rz(-rz) Ry(-ry) Rx(rx)` coordinate conversion.

The saved Run Action is a continuous six-second take with no cycle modifier: it clamps beyond its endpoint. Looping that take would reset the independent bob. Runtime therefore uses a restricted literal-expression evaluator of the **same source profile**, matching the actual take during its six seconds and explicitly continuing those expressions afterward. Gait phase and entity lifetime remain separate; stopping, restarting, Shift and R never restart lifetime. The core period is 0.625 seconds; the combined profile recurs after **720 seconds**. Bob retains **122.5 degrees/s** and its **245 degrees/s** harmonic. The imported six-second reference clip is deliberately non-looping; the runtime continuation has no six-second seam or frozen final pose.

This is fidelity to the saved research reconstructions, not a claim to reproduce every closed Minecraft controller state. Walk retains that study's omitted extra controller layers. Run retains its declared steady sprint, zero look/turn/terrain, body-type-zero and held-right assumptions. Negative directional-weight semantics and the absent original humanoid geometry remain documented source uncertainties. The reference video version is unverified; its observed cadence differs from this pack, so the scene retains the reconstructed Action cadence.

## Scene-local locomotion adaptations

A shared phase aligns receiving events at Walk source phase 0.22 and Run source phase 0.44. Speed-driven blending preserves that phase through Walk ↔ Run. Nominal travel is **1.8 m/s Walk** and **5.031 m/s Run**, with the source periods unchanged. These are gameplay calibration choices: in-place source geometry does not establish one exact no-slip world speed. Below nominal speed, cadence follows distance to avoid running feet at full speed while stationary.

The inherited single pose writer and inertial entry/exit transitions remain in use. Only transitions receive residual smoothing; steady source bounce, recovery and scale retain their original keys/expressions. A constant preview-floor alignment of 38 mm Walk / 33.674 mm Run is blended at Hips. Raw imported clips remain unchanged.

Straight rigid legs receive bounded contact corrections, up to 140 mm; no knees or ankles are added. Short scene-owned support windows use rolling lowest sole corners, allowing the block foot to rock while its current support edge remains planted. Corner handoff is a new physical point and is excluded from same-point slide metrics. Support duration latches at receiving contact and may shorten, but cannot widen to re-ground a leg already in swing. Replanting releases old rolling anchors; scale exit is inertialized on both start and stop. When rapid pivots exceed the translation budget, vertical clearance takes priority over horizontal lock. Extreme repeated taps can release/slip within that budget; they do not stretch the rig farther or force feet through the floor. These contact/transition adaptations are not additional proprietary controller data.

## Release exclusion

Keep **Actions & Stuff Research Export Guard** enabled in Project Settings → Plugins. It unconditionally skips this scene, the entire `scenes/dev/actions_stuff_research/` subtree and its own editor addon in normal exports, including all-resources exports. Production scenes have no research dependencies. A real PCK export with empty exclusion filters was checked against a plugin-disabled negative control; WorldMap remains present and source-derived resource payloads are absent from the guarded package. Godot may retain resource path strings in UID metadata; these are not animation assets. Recovery-mode exports bypass editor plugins and must not be used for commercial builds containing this workspace.

## Validation

Tests inside `tests/` exercise the actual imported clips and runtime evaluator against saved Blender fixtures, source scale, lifetime independence, phase exchange, start/stop, reset and interruption. Run with Godot `--headless --audio-driver Dummy --path game_mobile_3d --script res://scenes/dev/actions_stuff_research/tests/test_source.gd`, and similarly `test_gameplay.gd`, `test_support_exchange.gd`, `test_interruptions.gd`. Pass `-- 60` to the gameplay test for its 60 FPS deterministic pose check. Reports use Godot's `user://` directory. Across 1,271 fixture times, runtime/source Walk positions differ by at most 0.78 micrometres and scale by 0.50 ppm. The separately imported dense six-second Run reference differs by at most 20.58 micrometres and 8.11 ppm scale from sampled PRS interpolation and Godot key-time precision; the literal runtime evaluator retains the tighter source agreement. Deterministic 30/60 FPS tests and 44 interruption cases keep displayed feet above the floor within float noise. Seven actual-controller cases at 30 render FPS cover turns, taps, Shift pulses and R; extreme reversals/taps can exhaust the bounded horizontal contact budget.

Native Metal/Mobile 30 FPS gameplay capture and source/export/preservation audit evidence are retained in the session's `experiments/actions_stuff_walk_run_scene_v001` review folder. Desktop checks do not establish phone performance or artistic approval.
